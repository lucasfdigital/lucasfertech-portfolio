# lucasfertech-portfolio

Portfólio de Lucas Fernandes — Desenvolvedor Full Stack (React, Next.js, Node, Python, Mobile). Feito com React 19 + Vite + Tailwind CSS v4 + [BoardUI](https://www.boardui.com).

## Rodar local

```bash
npm install
npm run dev   # http://localhost:5173
```

## Build

```bash
npm run build
npm run preview
```

## Deploy na Vercel

Importe este repo na Vercel com os defaults de Vite: Build `npm run build`, Output `dist`. Sem env vars.
